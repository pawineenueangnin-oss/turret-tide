# Turret Tide: Zombie Defense

A mobile-first zombie survival web game (single HTML file, all art drawn in code).

- **v2 (current)**: lead your hero down the road, auto-shoot zombies, collect their coins and bring them back to build a base that fights back (turrets, walls, gates, hero upgrades, final boss).
  Play: https://pawineenueangnin-oss.github.io/turret-tide/
- **v1 (classic tower defense)**: https://pawineenueangnin-oss.github.io/turret-tide/v1.html
