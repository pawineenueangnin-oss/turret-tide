# Tusk Tide: Zombie Defense (formerly Turret Tide)

A mobile-first zombie survival web game (single HTML file, all art drawn in code, no network requests).

- **v3 (current) – Tusk Tide**: guide Little Tusk (น้องงา), an original cute Thai baby elephant who sprays water from his trunk at the nearest zombie. Collect magnet coins, stand on build pads to raise gun turrets and Thai multi-arrow towers, hold the cliff against a massive horde marching along the path below, and watch the camp transform into a Thai fortress (3 tiers).
  Play: https://pawineenueangnin-oss.github.io/turret-tide/
- **v2 (hero + base building)**: https://pawineenueangnin-oss.github.io/turret-tide/v2.html
- **v1 (classic tower defense)**: https://pawineenueangnin-oss.github.io/turret-tide/v1.html
